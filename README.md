# FIRESYNC

## Sensor-Aware Satellite Fire Intelligence System

Two satellites. Different views. One clearer picture of fire activity.

### Mission
Build a scientifically transparent web application that harmonizes
MODIS and VIIRS active-fire observations into an understandable
historical fire activity calendar.

### Initial Study Region
Bandipur, Karnataka, India.

### Technology
- Python 3.12
- Pandas and NumPy
- GeoPandas and Shapely
- DuckDB and Parquet
- SciPy
- Streamlit
- Plotly and PyDeck
- Pytest

### Scientific Principles
- Preserve original satellite observations.
- Keep sensor and satellite identities separate.
- Document spatial and temporal comparison assumptions.
- Never treat a hotspot as automatically confirmed wildfire.
- Make analysis reproducible and testable.

### Project Status
Foundation and dependency setup completed.
